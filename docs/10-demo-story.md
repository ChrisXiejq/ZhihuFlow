# 演示与秋招叙事

## 1. 三分钟 Demo 脚本

1. **痛点（20 秒）**：小商家有很多真实素材，但热点、策划、审核、发布和复盘散落在不同工具中；AI 文案工具无法保证品牌一致与内容安全。
2. **输入（20 秒）**：选择“咖啡店主理人”账号、上传门店/产品素材、选中一张带来源的高温热点卡、选择“下班探店”剧本。
3. **导演（40 秒）**：展示导演 Agent 的 CreativeBrief：为什么选这个角度、使用哪些素材、采用什么 Hook、预算与风险。
4. **生产（45 秒）**：展示标题、正文、6 页图文分镜和封面；点击素材来源查看真实图和版权状态。
5. **安全（30 秒）**：故意输入“全城最健康、喝了减肥”，展示 Policy Gate 拦截并建议修改；提交审核后保留完整审计。
6. **交付与复盘（25 秒）**：批准后进入内容日历，导出草稿/进入辅助发布；Trace 面板展示模型成本、耗时和评测结果。

## 3. 面试高频问题

### 为什么需要导演 Agent？

它只负责战略层创意简报和受限委派，不直接发布或任意调用工具。这样确保热点、账号人设、商业目标、素材权利和内容形式在生产前统一，避免多个生成 Agent 输出互相冲突。

### 为什么不直接全自动发布？

第三方平台的授权能力、内容责任和账号风控都是产品边界。RedFlow 的价值是提升创作与运营决策效率，发布必须遵守官方能力、频控与人工审核；MVP 采用草稿/辅助发布模式。

### 如何处理模型幻觉？

事实与营销断言必须有证据 ID；缺证据则标记待核实。结构化输出经过 Schema 校验，Policy Gate 独立复核，高风险内容需要人工审批。

### 如何判断 Agent 有用？

不以“爆款率”作为唯一指标。离线看安全召回、事实覆盖、轨迹合法性与风格一致；线上看内容包采纳率、编辑原因、端到端耗时、成本和经授权的内容表现变化。
