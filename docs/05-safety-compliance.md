# 内容安全、隐私与平台合规

## 1. 立场

RedFlow 是用户创作的辅助与治理工具，不承诺流量，不规避平台规则，不伪造真实体验，不进行批量或未授权账号操作。平台接入能力会变化，因此产品按“能力可用、授权明确、人工可控”的原则实现。

## 2. 发布分级

| 模式 | 行为 | MVP 支持 |
| --- | --- | --- |
| Draft Only | 导出图文、视频、标签与说明 | 是 |
| Assisted Share | 使用官方提供的应用内分享/发布能力，由用户确认 | 是，取决于授权能力 |
| Authorized Publish | 经平台审核、应用资质和用户授权的 API 发布 | 后续，按平台许可 |

禁止：模拟登录、破解验证码、代理规避、批量多账号发帖、刷量、自动化虚假互动。

## 3. 审核策略

### 规则层

- 联系方式、二维码、外链、身份证/手机号/地址等 PII。
- 绝对化、夸大、无法验证的宣传表达。
- 医疗、金融、法律、未成年人等高风险分类词。
- 禁用词、品牌词、价格/活动日期与商品事实不一致。
- 素材权利未知、竞品素材、重复率过高。

### 模型层

- 上下文语义判断：夸大暗示、误导性对比、歧视、攻击、虚假承诺。
- 多模态判断：图片文字、人体/未成年人、品牌 Logo、可疑导流元素。

### 人工层

- `MEDIUM`：显式确认并保存理由。
- `HIGH`：仅管理员/审核人可在修订后提交复审；不得直接批准。
- `BLOCKED`：系统拒绝生成发布任务。

## 4. 资产权利

资产必须标注：拥有、已授权、用户提供、AI 生成、未知。未知来源默认不可发布。对含人物的素材，额外记录肖像授权状态。生成图/视频输出携带生成模型、时间、Prompt 版本和人工编辑记录。

## 5. 隐私与数据治理

- 上传前与模型调用前检测并按需遮蔽 PII。
- 对象存储私有读；预签名 URL 短时有效；文件哈希去重。
- OAuth token 和平台密钥仅加密存储，绝不进入日志、Prompt 或浏览器。
- 支持资源删除、导出与按租户清理；默认 Trace 保留 30 天，聚合指标可延长。
- 对外部模型调用，提供供应商开关与“禁止发送原始素材”配置。

## 6. Prompt 注入防护

趋势文本、评论、网页摘要、OCR 文本均是不可信输入。它们只能作为引用数据，不能修改系统指令、工具权限、审核级别或发布策略。工具参数必须由服务端 Schema 验证，模型输出不得直接执行。

## 7. 审计要求

必须记录：内容版本、素材来源、规则版本、风险项、审批人、发布时间、发布通道、失败回执与撤销动作。审计记录只增不改，管理员不能删除自身审批记录。
