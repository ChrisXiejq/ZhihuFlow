# PRD：RedFlow 多模态内容增长 Agent

**版本**：v0.1  
**状态**：MVP 定义  
**负责人**：待定

## 1. 用户故事

### US-01：建立账号创作上下文

作为创作者，我希望配置人设、目标受众、禁用表达、品牌事实和内容风格，使生成结果长期一致。

**验收**：用户能新建账号画像；每个字段有版本号；导入过往内容后可由系统生成“风格建议”，但必须由用户确认写入。

### US-02：获得可信热点选题

作为运营者，我希望看到适合我账号的热点，而非泛热搜。

**验收**：每张趋势卡包含来源、抓取时间、热度、赛道适配度、风险、推荐角度和过期时间；缺少来源的趋势不可被直接用于生成。

### US-03：用剧本生成内容包

作为内容创作者，我希望选择一个热点和剧本，得到可编辑的标题、正文、分镜、封面建议和话题。

**验收**：一次生成至少给出 3 个标题、1 个正文、6 页以内图文分镜或 30 秒以内视频分镜、素材需求清单、CTA 和风险报告。

### US-04：用已有素材完成内容

作为商家，我希望上传门店照片和产品视频，系统优先使用我的真实素材，而不是虚构商品。

**验收**：素材可被自动打标签和 OCR；内容包列明每页/每镜头使用的资产；未知版权资产不得自动进入发布候选。

### US-05：审核与排期

作为团队管理员，我希望审核人能查看证据、编辑内容、批准或驳回，并在日历中排期。

**验收**：审核记录包含操作者、版本、意见、时间和最终决策；高风险内容无法跳过审核；排期冲突有提示。

### US-06：辅助发布与复盘

作为创作者，我希望以平台允许的方式把已批准内容交付到发布端，并查看表现带来的下一轮建议。

**验收**：MVP 至少支持 ZIP/剪贴板草稿导出和“辅助发布”适配接口；发布记录与内容版本绑定；无数据授权时清楚标记“无数据，不能归因”。

## 2. 核心流程

1. 用户创建工作区、账号画像、品牌规则和内容剧本。
2. 用户上传/导入素材，或选择带证据的趋势卡片。
3. 导演 Agent 产出 `CreativeBrief`；用户可以修改并确认。
4. 子 Agent 按 Brief 生成文案、分镜、素材编排与封面建议。
5. 合规 Gate 产出风险报告；高风险内容阻塞。
6. 用户在编辑器中修改，提交审核或直接批准（取决于角色/风险）。
7. 批准的内容进入日历，并经 Publisher 输出草稿或使用官方授权能力辅助发布。
8. 系统采集用户授权的表现数据，复盘 Agent 给出下一轮实验建议。

## 3. 功能需求

### 3.1 工作区与权限

- 多租户隔离：所有资源有 `tenant_id`。
- 角色：Owner、Editor、Reviewer、Viewer。
- Owner 管理连接器、额度、发布策略；Reviewer 可审批但不可改权限。

### 3.2 内容操作台

- 趋势列表、筛选和收藏。
- 内容卡片状态：`DRAFT / GENERATED / NEEDS_REVIEW / APPROVED / SCHEDULED / PUBLISHED / FAILED / ARCHIVED`。
- 编辑器包含标题、正文、标签、分镜、素材引用、风险和版本差异。
- 支持从历史高表现内容创建“变体”，不允许无提示复制。

### 3.3 内容剧本

- 系统剧本：教程、测评、清单、Vlog、探店、避坑、故事。
- 用户剧本：目标、受众、语气、叙事结构、视觉规则、禁用词、CTA 规则。
- 剧本版本化；每个内容包永久记录所用版本。

### 3.4 资产管理

- 上传图片/视频/音频/文档；生成缩略图、OCR、标签、Embedding。
- 手动编辑资产描述和权利状态。
- 资产状态：`OWNED / LICENSED / GENERATED / USER_PROVIDED / UNKNOWN`。
- `UNKNOWN` 不可直接用于待发布内容。

### 3.5 审核与合规

- 检测事实不一致、夸大性表达、敏感类别、联系方式、二维码、肖像/版权未知、文本重复。
- 风险等级：`LOW / MEDIUM / HIGH / BLOCKED`。
- `MEDIUM` 需要显式确认；`HIGH/BLOCKED` 只能经修订后重新评估。

## 4. 非功能需求

| 项目 | MVP 指标 |
| --- | --- |
| API 可用性 | 本地/测试环境 99%（不含外部模型） |
| 生成响应 | 生成任务异步；首个进度事件 < 3 秒 |
| 并发 | 10 个活跃工作区、每工作区 3 个并行任务 |
| 可追溯性 | 100% Agent run 有 trace_id、输入版本和模型信息 |
| 隔离 | 任意租户查询均带 tenant 过滤；服务端强制校验 |
| 可编辑性 | 所有生成内容在发布前可修改且保留版本 |

## 5. 页面信息架构

```text
登录
└── 工作区
    ├── 首页（今日计划、待审核、趋势摘要）
    ├── 趋势雷达
    ├── 创作工作台
    │   ├── Creative Brief
    │   ├── 内容编辑器
    │   └── 风险报告 / Trace
    ├── 素材库
    ├── 剧本与账号
    ├── 内容日历
    ├── 复盘分析
    └── 设置（成员、连接器、额度、策略）
```

## 6. 明确不做的需求

- “一键无限量生成并自动发布”。
- 预测某条内容一定爆火。
- 以爬虫、模拟浏览器或绕过风控的方式操作第三方账号。
- 以模型输出代替法律、医疗、金融或广告合规意见。
