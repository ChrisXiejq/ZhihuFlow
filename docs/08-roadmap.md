# 交付路线图

## 阶段 0：冻结范围与云账号准备（2 天）

- 选择一个验证垂类：咖啡/轻食本地生活或求职知识 IP。
- 写 20 个真实风格的内容任务，确定第一版剧本。
- 完成 Wireframe、数据模型和接口契约。
- 确定 ECS 地域/VPC；创建 RAM 最小权限用户；准备域名、测试子域名和预算告警。

## 8 周 MVP

| 周次 | 交付物 | 退出条件 |
| --- | --- | --- |
| W1 | Monorepo、Docker Compose、登录、工作区、账号画像、剧本 CRUD | 本地一条命令启动；用户可创建账号和剧本 |
| W2 | 素材上传、对象存储、OCR/标签、素材库页面 | 图片能分析并带权利状态 |
| W3 | 趋势卡片导入、评分、选题页面 | 每张卡有来源/时间/过期机制 |
| W4 | 导演 Agent、CreativeBrief、SSE 进度 | 可生成结构化 Brief 并中断补充信息 |
| W5 | Writer/Visual Planner、图文内容包、编辑器 | 可得到可编辑图文分镜和标题 |
| W6 | Policy Gate、审核、内容版本、日历 | 高风险无法绕过审核 |
| W7 | 草稿导出、辅助发布适配层、Trace、成本面板 | 已批准内容可导出且有审计 |
| W8 | Eval 基准集、CI 门禁、Docker、录屏 Demo | 一键运行、可演示、可回归测试 |

## 上线冲刺（W9–W10）

| 周次 | 交付物 | 退出条件 |
| --- | --- | --- |
| W9 | 阿里云 VPC/安全组、OSS、RDS、Tair、ACR、ECS Compose | 测试域名可 HTTPS 访问；应用与数据服务均为私网连接 |
| W10 | 备份/恢复演练、监控告警、灰度发布、压测和安全复核 | 能在 1 小时内恢复数据库；上线检查清单全绿 |

## 后续迭代

- V1.1：短视频素材自动编排、字幕与模板渲染。
- V1.2：授权数据导入、实验管理与复盘 Agent。
- V1.3：团队协作、品牌资产、审批流、更多 Publisher。
- V2：垂直行业剧本市场、付费、企业私有部署。

## 2–3 人分工

| 角色 | 主责 | 辅责 |
| --- | --- | --- |
| Agent/后端 | 工作流、模型网关、Policy、数据层、评测 | 基础部署 |
| 前端/产品 | 工作台、素材库、编辑器、审核日历 | UX/埋点 |
| 多模态/平台 | 媒体管线、渲染、连接器、数据/运营 | 测试与内容剧本 |

单人开发时严格按 W1–W6 实施；视频渲染、真实平台连接和高级数据分析都放在 W7 以后。W9–W10 不应省略：线上部署是项目交付的一部分，而非最后临时复制代码。
